La plateforme Belle Vitesse repose sur une architecture robuste où Flask agit comme le chef d'orchestre entre les sources de données, les générateurs de documents (PDF) et le stockage cloud direct (kDrive Infomaniak).

Composants Principaux

1. Flask (Le Noyau)

L'application est structurée en Blueprints (admin, public) pour séparer proprement la logique de gestion et l'interface client.

  • Routes Admin : Dashboard, gestion des projets, contacts et outils.
  • Routes Publiques : Landing pages, formulaires de signature et consultation de documents.

2. Airtable & MySQL (La Dualité du Stockage)

Nous utilisons une approche hybride pour bénéficier du meilleur des deux mondes :

  • Airtable : Utilisé comme interface de saisie "No-Code" pour le catalogue (véhicules, têtes, produits). Les données sont synchronisées manuellement via un script sur le serveur vers MySQL.
  • MySQL : Utilisé pour les données transactionnelles rapides (signatures, logs, sessions, configurations de projets spécifiques).

3. WeasyPrint (Moteur de Rendu)

Le moteur WeasyPrint convertit les templates Jinja2 + CSS en documents PDF professionnels. La DA (Direction Artistique) est strictement contrôlée via des variables CSS partagées entre le web et le PDF.

Note sur la Synchronisation

Le service sync_airtable.py assure que MySQL contient une copie fraîche des données Airtable. Toute modification sur Airtable nécessite un déclenchement de synchro pour être visible sur le site public.

Sécurité des Accès

L'accès administratif est protégé par un système de Magic Link (envoi par email) pour éviter la gestion complexe de mots de passe, complété par un décorateur @require_roles au niveau des routes.
