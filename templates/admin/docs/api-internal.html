API & Webhooks

La plateforme communique avec des services tiers via une API REST interne et un système de webhooks sortants, principalement gérés par n8n.

API Administrative

Utilisée par le tableau de bord pour les mises à jour de statut en temps réel sans rechargement de page.

  • Base URL : /admin/api/v1
  • Authentification : Session administrative ou Jeton Bearer JWT (pour accès externe).

Endpoints Majeurs

Méthode Route Description
POST /status/update Met à jour l'état d'une inspection ou décharge.
GET /projects/list Récupère la liste filtrée des projets.

Webhooks Sortants (n8n)

Le module utils/n8n.py centralise l'envoi de données vers l'outil d'automatisation.

Événements Déclencheurs

  • Signature Finalisée : Envoi du JSON complet et du chemin PDF pour archivage.
  • Projet Créé/Supprimé : Notification aux systèmes de production.
  • Alerte Erreur : Notification en cas d'échec critique (ex: échec SMTP).

Structure d'un Payload Webhook

# Exemple de données envoyées à n8n
{
    "event": "inspection_signed",
    "project_id": "BVPR-1234",
    "inspection_id": "recAbc123",
    "type": "checkin",
    "pdf_url": "https://bellevitesse.com/document/..."
}

API Publique (Waivers)

Une couche API minimale existe pour supporter le processus de signature sur les appareils mobiles (tablettes).

  • Endpoint : /waiver/sign/<token>
  • Sécurité : CSRF désactivé spécifiquement pour ces routes (via @csrf.exempt) pour permettre la soumission depuis n'importe quel navigateur sans contrainte de session, tout en validant le token unique.

Délais d'Expiration (TTL)

Les jetons de signature ont une durée de vie limitée définie dans le .env (par défaut 24h). Passé ce délai, le webhook n8n ou le bouton admin doit générer un nouveau lien.
