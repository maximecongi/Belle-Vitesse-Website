Comment ça marche ?
Générez un lien calendrier pour chaque utilisateur. Ce lien permet de s'abonner au calendrier des projets Belle Vitesse depuis iPhone, Android, Outlook ou Google Calendar. Le calendrier se met à jour automatiquement lorsqu'un nouveau projet est créé.
Instructions d'abonnement
iPhone : Réglages → Calendrier → Comptes → Ajouter → Autre → Calendrier par abonnement → Coller l'URL
Android / Google Calendar : Depuis un PC → Google Calendar → "+" → "À partir d'une URL" → Coller l'URL
Outlook : Ajouter un calendrier → Depuis Internet → Coller l'URL
Ou scannez le QR code directement depuis le téléphone.
