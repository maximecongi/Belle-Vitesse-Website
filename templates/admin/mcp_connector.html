💡 Procédures de connexion

{# #}

1. Dans Claude, rendez-vous dans Paramètres ➔ Connecteurs.

2. Cliquez sur Ajouter en haut à droite et collez l'URL avec votre clé d'accès :

https://team.bellevitesse.com/mcp?token=<VOTRE_CLÉ_API_IA>
{#

Dans votre terminal Mac, exécutez la commande d'enregistrement officielle :

claude mcp add --transport http --header "Authorization: Bearer <VOTRE_CLÉ_API_IA>" bv-mcp https://team.bellevitesse.com/mcp

Dans votre fichier claude_desktop_config.json ou dans les paramètres Cursor :

{
  "mcpServers": {
    "BV-MCP": {
      "url": "https://team.bellevitesse.com/mcp",
      "headers": {
        "Authorization": "Bearer <VOTRE_CLÉ_API_IA>"
      }
    }
  }
}
#}
